# Prompt Planning

The system will use four prompts.

1. Summarization Prompt
- Summarize one chunk.
- Preserve facts.
- Do not invent information.

---

2. Insight Extraction Prompt

Extract:

- Background
- Challenge
- Strategy
- Execution
- Results
- Learning

---

3. Case Study Generation Prompt

Generate a structured business case study using only extracted insights.

---

4. Evidence Mapping Prompt

Match every generated sentence with supporting evidence chunks.

If no supporting evidence exists,
return "Weak Evidence".
